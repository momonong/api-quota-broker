# Provider evidence, reviewed 2026-09-25

These are public product facts, not confirmation of any user's account eligibility or remaining quota. Free eligibility and billing facts in config.local.json must be checked independently and given a short expiration. Provider limit and remaining facts are recorded separately from positive local safety caps, each with provenance, time, source and scope. Unknown official values stay null. The demo's account is a fixture only.

| Provider | Primary source and observed fact | v0.1 treatment |
| --- | --- | --- |
| Google Gemini Developer API | [Rate limits](https://ai.google.dev/gemini-api/docs/rate-limits): RPM, input TPM and RPD; limits depend on project tier, apply per project rather than per key, and RPD resets at Pacific midnight. Active limits are shown in AI Studio. | Use project-scoped local safety buckets; record official project limits and remaining only when actually known. Model access and free tier remain unverified by default. |
| Google Gemini Developer API | [Pricing](https://ai.google.dev/gemini-api/docs/pricing) and [billing](https://ai.google.dev/gemini-api/docs/billing): selected models have free-tier pricing, billing changes the tier and possible charges. [Gemini 2.5 Flash-Lite model](https://ai.google.dev/gemini-api/docs/models/gemini-2.5-flash-lite): 1,048,576 input and 65,536 output tokens; access to 2.5 models is currently limited for some new projects. | One text model is listed; account-specific access and billing must be confirmed. |
| Google Gemini Developer API | [Generate content API](https://ai.google.dev/api/generate-content): official generativelanguage.googleapis.com endpoint and usageMetadata.promptTokenCount. [Troubleshooting](https://ai.google.dev/gemini-api/docs/troubleshooting): official SDKs may automatically retry. | Direct REST call with no SDK auto-retry; report observed input tokens. |
| Cloudflare Workers AI | [Pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/): free allocation measured in Neurons, with daily reset at 00:00 UTC; Workers Paid can bill beyond the allocation. [Limits](https://developers.cloudflare.com/workers-ai/platform/limits/): text-generation request-rate limit and some paid-model exceptions. | Local Neuron and request-rate safety buckets, billing disabled requirement. Official account remaining may be unknown. Do not convert response token counts into certain Neurons. |
| Cloudflare Workers AI | [REST API](https://developers.cloudflare.com/workers-ai/get-started/rest-api/) and [model catalog](https://developers.cloudflare.com/workers-ai/models/): official account endpoint and Cloudflare-hosted Meta @cf/meta/llama-3.2-1b-instruct, with text generation and 60K context. Its max_tokens input defaults to 256; the v0.1 broker uses 256 as a conservative cap, not as a provider maximum. [Errors](https://developers.cloudflare.com/workers-ai/platform/errors/): free-allocation exhaustion can return 429. | One model listed with Meta as author and Cloudflare as host; REST response without authoritative Neurons stays unknown. |
| NVIDIA API catalog | [NIM product FAQ](https://docs.api.nvidia.com/nim/docs/product): developer-program access and a separate 90-day AI Enterprise trial are described. | Separate executor candidate only; no shared broker target, official quota defaults, or production admission. Its modern profile distinguishes local safety caps from official quota facts. |

The source date is an inspection date, not a promise that provider terms or limits remain current. Account-specific tier, shared usage, quotas, billing switches and model availability were not verified; no live provider API call was made.
